 This repository is code for the capstone project for my software engineering degree. The project consists of a reading tracker app for Android written in Java. The app uses SQLite for its database and is thus completely functional offline/locally.
 
 An APK is easily downloadable from this URL: https://nchaney29.github.io/d424/
 
The APK is for demonstration purposes only. Please note the app requires the registration of a username and password and these values cannot be changed or recovered.
